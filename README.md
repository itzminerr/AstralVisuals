# AstralVisuals

## Автоматические обновления

При запуске клиент проверяет последний публичный GitHub Release. Если его тег новее установленной версии и к релизу прикреплён файл `AstralVisuals*.jar`, клиент скачивает и проверяет его. Установленный JAR заменяется только после закрытия Minecraft, поэтому новая версия начинает работать при следующем запуске.

Используйте для тегов релизов версии вида `v2.2` и прикладывайте к релизу JAR клиента, например `astralvisuals-2.2.jar`. Автообновление можно отключить параметром JVM `-Dastralvisuals.autoUpdate=false`.

AstralVisuals это визуальный и утилитарный мод для **Minecraft 1.21.4**

## Что изменилось в версии 2.0

- Добавлено автоматическое обновление клиента через GitHub Releases.

- Добавлены **Cooldowns**, **World Tweaks**, **Waypoint ESP**, **Sky Shader**, и **Hand Shader**.
- Удалены, улучшены и переименованы некоторые функции.

## Features

В следующем списке находятся модули, которые на данный момент есть в клиенте:

### Визуальные модули

- **Aspect Ratio** — изменяет соотношение сторон.
- **Better Minecraft** — изменяет стиль ванильных кнопок.
- **Block Overlay** — настраиваемые эффекты оверлея блока, его контура и шейдера.
- **Camera** — регулирует расстояние от третьего лица и добавляет настраиваемый зум.
- **China Hat** — рендерит китайскую шляпу для игрока и его друзей.
- **Client Color** — возможность выбора статических или анимированных 2/3 цветных акцентов, общие для всего клиента.
- **Cosmetic** — настраиваемые сферы, нимб, трейлы и плащи.
- **Crosshair** — заменяет стандартный прицел на настраиваемый.
- **Custom Hitbox** — кастомные хитбоксы энтити.
- **Hand Shader** — кастомный шейдер рук.
- **Hit Color** — меняет цвет и прозрачность оверлея урона.
- **Hit Effect** — рисует красивый эффект волны при ударе/взрыве кристалла.
- **Interface** — настройки GUI и HUD.
- **Jump Circle** — рисует круг в месте прыжка игрока.
- **Kill Effect** — добавляет эффект при убийстве/попе тотема игрока.
- **Motion Blur** — добавляет размытие в движении.
- **No Render** — убирает лишнее.
- **Particles** — добавляет разные частицы при ударе/в мире.
- **Predictions** — рендерит траектории полета перлов/стрел/зелий.
- **Self Nametag** — рендерит неймтаг игрока от 3 лица.
- **Sky Shader** — добавляет настраиваемый шейдер неба.
- **Swing Animation** — изменяет анимацию удара.
- **Target ESP** — выделяет текущую цель с настраиваемыми эффектами.
- **View Model** — изменяет позицию и размер обеих рук.
- **Waypoint ESP** — рендерит метки в мире.
- **World Tweaks** — настройки тумана, яркости, погоды и времени.

### Утилитарные модули

- **Auto Duel** — автоматически отправляет запросы на дуэль.
- **Auto Respawn** — автоматически возрождается после смерти.
- **Auto Sprint** — автоматический бег.
- **Card Checker** — проверяет на наличие вагонеток в мире.
- **Click Pearl** — бросает эндер-жемчуг по бинду.
- **Cooldowns** — показывает кулдауны на предметы.
- **Crystal Optimizer** — оптимизатор кристаллов.
- **Discord RPC** — отображает активность в дискорде.
- **Fake Player** — спавнит фейк игрока.
- **Free Look** — свободный обзор камеры по бинду.
- **Item Scroller** — упрощает перемещение предметов в инвентаре.
- **Item Swap** — смена предметов в правой руке по бинду.
- **Lock Slot** — блокирует выбранные слоты хотбара.
- **Tape Mouse** — настраиваемый автокликер.

## HUD

- Potions (Действующие Зелья)
- Hotkeys (Горячие клавиши)
- Inventory (Инвентарь)
- Notifications (Уведомления)
- Coordinates (Координаты)
- Waypoints (Вейпоинты)


## Команды

Дефолтный префикс команд - `.`. Доступные команды:

- `.help` — отображает доступные команды и помощь по ним.
- `.bind` — возможность изменять, добавлять и удалять бинды.
- `.config` — возможность добавлять и удалять конфиги.
- `.friend` — возможность добавлять и удалять друзей.
- `.macro` — возможность создавать чат макро.
- `.way` — возможность создавать вейпоинты.
- `.prefix` — возможность изменять префикс команд.
